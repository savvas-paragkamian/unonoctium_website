# unonoctium.gr — Academic Profile Website

Personal academic website for Savvas Paragkamian.  
Domain: www.unonoctium.gr · GitHub: savvas-paragkamian

---

## What this is

A self-hosted static academic profile site. Hugo compiles markdown content into a `public/` directory. Podman runs an nginx container serving that output. No runtime server code, no database, no CMS.

---

## Tech stack

| Layer | Tool | Version |
|---|---|---|
| Site generator | Hugo extended | 0.162+ (via pixi) |
| Styling | Hand-written CSS | ~380 lines, no framework |
| Container | Podman (rootless) + nginx:1.27-alpine | — |
| Python tooling | pixi-managed venv | bibtexparser, cairosvg, requests |
| Languages | Hugo i18n | English (en) + Greek (el) |

**Hugo is a build-time tool only** — it is not installed in the container. The Dockerfile copies the pre-built `public/` into nginx:alpine. This keeps the image small and eliminates Hugo version drift in production.

---

## Makefile commands

```sh
make dev          # Hugo live-reload at http://localhost:1313/en/ (shows drafts)
make build        # runs bib2data.py if bib present, then hugo --minify → public/
make pubs         # converts data/publications.bib → data/publications.yaml only
make container    # make build + podman build + podman run on port 8080
make stop         # stops and removes the running container
make clean        # deletes public/ and resources/
```

All Hugo and Python invocations go through `pixi run` — never call them directly.

## Navigation and sidebar

The site has **no traditional top navigation links**. The nav bar shows only:
- `UNONOCTIUM` (brand, links to `/`)
- `MENU` (label for a hidden checkbox that toggles the sidebar)

The sidebar is a CSS-only slide-in panel driven by `input#menu-toggle` (checkbox). No JavaScript is needed for open/close. The overlay uses `backdrop-filter: blur` with a `@supports` fallback for older browsers.

Sidebar links (in order):
1. Bits
2. Stories
3. Publications
4. About
5. Notes

Language switcher (EN ↔ EL) lives at the bottom of the sidebar.

## Homepage

`layouts/index.html` renders a two-part page:

1. **Hero** — balloon logo (large, centered), author name, tagline, external links
2. **Section feed** — horizontal-rule-separated sections pulling live content:
   - Latest 2 Stories (title + summary + date)
   - Latest 6 Bits (title + date, list)
   - Latest 3 journal articles from `data/publications.yaml`
   - Latest 4 Notes (title only)

Sections only render if content exists — no empty blocks appear.

## Logo

`logo.svg` is the balloon-with-network illustration used as the site identity (inspired by the Steve Jobs Archive tree treatment — large, centered, dominant on the homepage).

To regenerate after design changes:
```sh
pixi run python scripts/make_logo.py
```

This overwrites both `logo.svg` and `logo.png` in the repo root.

## Publications pipeline

1. Copy the latest bib from the CV repo: `cp .../Curriculum_Vitae/publications.bib data/publications.bib`
2. Run `make pubs` → `scripts/bib2data.py` writes `data/publications.yaml`
3. Hugo reads `hugo.Data["publications"]` in templates (note: use `hugo.Data`, not `.Site.Data` — deprecated in Hugo 0.156)
4. Entries are grouped by `type`: `article`, `preprint`, `thesis`, `book`
5. Never edit `data/publications.yaml` by hand

## CSS architecture

Single file: `assets/css/main.css`. Hugo minifies and fingerprints it; the `<link>` tag in `head.html` includes the SRI integrity hash automatically.

Key design tokens (CSS custom properties):
```css
--bg:      #ffffff
--ink:     #0c0c0a
--mid:     #484840
--dim:     #8c8c84
--rule:    #e5e2db
--serif:   Georgia, 'Times New Roman', serif
--sans:    ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, sans-serif
--gap:     clamp(1.5rem, 4vw, 3rem)
--measure: 60ch
--nav-h:   4.4rem
```

Typography follows the Steve Jobs Archive approach: pure white background, near-black text, large fluid serif for display (`clamp(2.2rem, 5.5vw, 4.2rem)`), negative letter-spacing (`-0.02em`) on headings, small uppercase sans-serif (`0.60–0.65rem`, `0.18–0.24em` tracking) for labels and navigation.

---

## Sticky navigation

The nav is `position: sticky; top: 0` with `background: var(--bg)`. A thin border-bottom is transparent at rest and transitions to `var(--rule)` on scroll. A 3-line passive scroll listener in `baseof.html` toggles the `.nav-scrolled` class:

```js
(function(){var n=document.querySelector('nav');window.addEventListener('scroll',function(){n.classList.toggle('nav-scrolled',window.scrollY>8);},{passive:true});})();
```

## Bilingual guide

- Always write English content first in `content/en/`
- Mirror the file path in `content/el/` for the Greek version
- UI strings (nav, footer, section labels) live in `i18n/en.yaml` and `i18n/el.yaml`
- Hugo falls back to English if a Greek file is missing
- Auto-translate drafts: `DEEPL_API_KEY=xxx make translate`
- Manual translations always take precedence over auto-generated ones

---

## Cross-platform notes

- `backdrop-filter`: wrapped in `@supports`; solid white fallback for Firefox < 103
- `100dvh`: declared after `100vh` so old browsers use the fallback silently
- `gap` in flexbox: Safari 14.1+ required; graceful degradation on older Safari
- Touch targets: all interactive elements (`menu-btn`, `sidebar-close`, `sidebar-nav a`, nav links) have `min-height: 44px`
- `prefers-reduced-motion`: hero and about animations are disabled
- `overflow-x: hidden` on body prevents horizontal scroll on narrow viewports
- Print stylesheet hides nav/sidebar, shrinks logo

## Deployment

```sh
# macOS: start Podman VM once per machine restart
podman machine start

# Build + containerise + run
make container          # → http://localhost:8080

# Rebuild after content changes
make build && make container

# Stop
make stop
```

**Production TLS** — put Caddy in front on the server:
```
unonoctium.gr {
    reverse_proxy localhost:8080
}
```

Caddy issues and renews Let's Encrypt certificates automatically.

## Design inspiration

**Steve Jobs Archive** (https://stevejobsarchive.com/) — primary aesthetic reference.

- Pure white background (`#ffffff`), near-black text (`#0c0c0a`)
- Large fluid serif for names and headlines; tight negative tracking (`-0.02em`)
- Ultra-small uppercase sans-serif for labels, nav, meta (`0.62rem`, `0.20em+` tracking)
- The logo (balloon) is the dominant visual — displayed large and centered on the homepage
- Generous whitespace; horizontal rules as section separators
- No decorative color, no cards, no shadows beyond what is strictly necessary
